# ContentStash Icon Options

Ten SVG-first replacement directions for the Chrome extension icon.

These avoid text-heavy marks so the toolbar icon remains readable at 16 px and the popup mark can be enlarged without pixelation.

## Options

- 01-stacked-pages: Stacked Pages. A clear saved-content metaphor: layered pages with a confident teal cover.
- 02-bookmark-stash: Bookmark Stash. Simple and extension-native: a bookmark held inside a compact archive shape.
- 03-capture-corners: Capture Corners. A browser-capture signal: four corners locking onto a saved page.
- 04-inbox-drop: Inbox Drop. Fast-save energy: content dropping into a sturdy local inbox.
- 05-folder-spark: Folder Spark. A polished stash/folder mark with a small signal that content was captured.
- 06-page-pin: Page Pin. A page plus location pin, useful if the product promise is “save this exact page.”
- 07-vault-card: Vault Card. Most premium of the set: saved content as a protected object, not just a bookmark.
- 08-link-stack: Link Stack. Best for “save from anywhere”: link capture plus stacked-content memory.
- 09-refined-cs: Refined CS. A grown-up monogram option, kept simple enough to read at popup size.
- 10-compass-save: Compass Save. A distinct save/navigation hybrid: content selected, carried, and kept.

## Export note

Use the selected SVG as the source of truth, then export true PNG files at 16, 48, and 128 px for the Chrome extension manifest.
